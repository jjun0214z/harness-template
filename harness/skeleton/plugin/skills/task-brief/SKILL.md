# 과제 브리프

작업자는 오케스트레이터의 대화를 모른다. **브리프 한 장만 보고 일할 수 있어야 한다.**

## 형식
```
목표: <한 문장>
저장소: <저장소 키 하나. 키 목록은 `CLAUDE.md` 「저장소 지도」에 있다>. 이 저장소만 고친다
배경: <왜 하는지 두세 줄. {{owner}} 지시 원문이 있으면 인용>
읽을 곳: <파일 · 문서 경로>
완료 조건: <무엇이 통과하면 끝인가. 검사 명령 포함>
하지 말 것: <이번 과제에서 특히 건드리면 안 되는 것>
```

## 쪼개는 기준
- 과제 1 = 저장소 1. 저장소를 가로지르면 과제를 나누고 순서를 정한다.
- 같은 저장소에 작업자를 여럿 둘 때는 과제마다 별도 워크트리 · 브랜치를 쓰고 맡는 파일 범위를 나눠 적는다.
- 판단에 사실이 모자라면 과제 전에 `researcher` 에게 먼저 묻는다.
