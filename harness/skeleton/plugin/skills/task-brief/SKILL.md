# 과제 브리프

작업자는 오케스트레이터의 대화를 모른다. **브리프 한 장만 보고 일할 수 있어야 한다.**

## 형식
```
목표: <한 문장>
저장소: <저장소 키 하나. 키 목록은 `CLAUDE.md` 「저장소 지도」에 있다>. 이 저장소만 고친다
배경: <왜 하는지 두세 줄. {{owner}} 지시 원문이 있으면 인용>
읽을 곳: <파일 · 문서 경로>
완료 조건: <무엇이 통과하면 끝인가. 검사 명령 포함>
하지 말 것: <이번 과제에서 특히 건드리면 안 되는 것>
```

## 쪼개는 기준
- 과제 1 = 저장소 1. 저장소를 가로지르면 과제를 나누고 순서를 정한다.
- 같은 저장소에 작업자를 여럿 둘 때는 과제마다 별도 워크트리 · 브랜치를 쓰고 맡는 파일 범위를 나눠 적는다.
- 판단에 사실이 모자라면 과제 전에 `researcher` 에게 먼저 묻는다.

## 맡기는 방법
<!-- harness:begin dispatch-table (생성기가 관리한다. 이 블록 안은 고치지 않는다) -->
{{dispatch_table}}
<!-- harness:end dispatch-table -->

- 띄우는 도구가 실패하면 조용히 다른 경로로 바꾸지 않는다. {{owner}}께 알리고 이슈로 남기고 도구부터 고친다.
- 한 과제에 Claude 와 Codex 를 같이 돌리지 않는다. 실제로 고른 엔진 하나의 사용량만 쓴다.

## 작업자가 끝나기 전에 치울 것
- **띄운 프로세스는 끄고 간다.** 끝 보고 전에 자기가 띄운 개발 서버 · 검수용 헤드리스 크롬(`--user-data-dir=/tmp/...`) · adb 서버를 pid 로 끈다(사용자 크롬 · crashpad 는 건드리지 않는다). 남아 있으면 작업 공간 삭제를 막는다.
  남은 것은 정리 스크립트(`finish_worker.py`)가 세션을 끝낸 뒤 끈다: 워크트리를 작업 폴더로 쓰거나 명령줄에 워크트리가 든 알려진 도구, 프로필이 워크트리 · 그 Claude 임시 폴더 안이거나 이름에 작업 이름이 든 검수 크롬. 그래서 검수 크롬 프로필은 `/tmp/<작업 이름>-chrome` 처럼 작업 이름을 넣거나 scratchpad 안에 만든다.
- **휴지통으로 보내지 않는다.** 다시 만들 수 있는 찌꺼기(검사용 사본 · 크롬 프로필 · 미리보기 · `__pycache__` · 브리프/보고 임시 파일)는 정확한 경로를 `rm -rf` 로 바로 지운다. `trash`(macOS `/usr/bin/trash`) · Finder 「휴지통으로 이동」 · `~/.Trash` 로 옮기기를 쓰지 않는다. 휴지통으로 보낸 찌꺼기는 용량이 그대로 남아 쌓인다(어떤 에이전트는 습관처럼 `trash` 를 고른다).
- 검사용 사본(git archive + 패키지 설치)은 검사가 끝나면 바로 지운다. 브리프 「완료 조건」에 사본 검사를 시켰으면 같은 줄에 「검사 끝나면 사본 삭제」를 적는다.
- `~/Documents` 와 사용자 파일은 지우지 않는다. 지워도 되는지 모르면 남기고 보고에 적는다.
