# 시작 (설치 다음 한 걸음)

**지금 할 것 딱 한 개만 말한다.** 여러 개를 나열하면 사용자는 다시 어리둥절해진다.
`setup` 스킬과 역할이 다르다: `setup` 은 설치 · 재설정 · 점검(doctor), `start` 는 **설치가 끝난 뒤의 다음 한 걸음**이다.

## 1. 먼저 상태를 읽는다 (사용자에게 묻지 않고 파일에서)

| 무엇 | 어디 |
| --- | --- |
| 코드 저장소 수 | `harness.json` 의 `repos` |
| 하네스 원격 | `harness.json` 의 `harness_repo.remote` |
| 채울 자리 남음 | `harness.json` `skills.fill` 에 든 스킬(`plugins/{{slug}}/skills/<이름>/SKILL.md`)에 `채울 자리` 주석이 남아 있는지 |
| 어디까지 왔나 | `상황판.md` 「지금 집중」 체크리스트 |

## 2. 위에서 처음 걸리는 하나만 제안한다

| 순서 | 이 상태면 | 제안하고 바로 한다 |
| --- | --- | --- |
| 1 | `repos` 가 비었다 | **코드 저장소 붙이기.** 이것이 먼저다(저장소가 없으면 채울 자리도 채울 수 없다). 3절로 간다 |
| 2 | `harness_repo.remote` 가 비었다 | **하네스 원격 만들기.** 이슈 추적 · 라벨이 여기서 켜진다. 4절로 간다 |
| 3 | 채울 자리가 남았다 | **규칙 채우기.** 5절로 간다 |
| 4 | 위가 다 끝났다 | **첫 과제 받기.** 「무엇을 만들까요?」라고 묻고, 답을 `task-brief` 형식으로 쪼갠다 |

제안은 한 문장 + 「지금 하겠습니까?」로 묻는다. 사용자가 다른 것을 하자고 하면 그것을 따른다.

## 3. 코드 저장소 붙이기

`setup` 스킬 「7-1. 저장소 추가」를 그대로 따른다(키 · 새로 만들기 / 원격 받기 / 이 컴퓨터 폴더 연결 · 폴더 · 브랜치 · 스택을 대화로 묻고 `{{py}} harness/scripts/bootstrap.py add-repo`).
끝나면 두 가지를 반드시 알린다:
1. **새 작업자 `<키>-worker` 는 지금 세션에서는 보이지 않는다.** 에이전트 목록은 세션이 시작할 때 읽히므로, 세션을 닫고 다시 열어야 쓸 수 있다.
2. 바뀐 하네스 파일(`harness.json` · 작업자 · 저장소 지도)을 경로를 명시해 커밋한다.

## 4. 하네스 원격 만들기

원격이 있어야 이슈 추적 · 라벨 · 이슈 목록 조회가 성립한다. 없으면 `상황판.md` 한 장으로만 버틴다.
1. `gh auth status` 로 로그인을 확인한다. 안 돼 있으면 `! gh auth login` 을 사용자가 직접 치게 안내한다.
2. 이름을 확인받고(`<조직>/<저장소>`) 비공개로 만든다: `gh repo create <조직>/<저장소> --private --source <하네스 폴더> --push`.
3. `harness.json` 의 `harness_repo.remote` 에 적고 `{{py}} harness/scripts/generate.py` 를 돌린다(이슈를 가리키는 문장이 그때 생성물에 들어간다).
4. 라벨은 `{{py}} harness/scripts/bootstrap.py run --create-github` 이 만든다.

사용자가 원격을 원하지 않으면 그대로 둔다. 그때는 `상황판.md` 가 작업 추적의 주인이라고 알리고 5절로 넘어간다.

## 5. 규칙 채우기

붙인 저장소에 **필요한 것만** 채운다. 파일과 절을 짚어 주고, 내용은 사용자에게 물어 받아 적는다.

| 스킬 | 무엇을 받아 적나 |
| --- | --- |
| `code-convention` | 저장소별 검사 명령(`harness.json` 의 `repos[].checks` 에 적으면 표가 다시 생성된다) · 언어 규칙 |
| `security-privacy` | 리뷰에서 되돌려보내는 기준 · 비밀 보관 자리 |
| `operations` | 환경 · 환경변수 자리 · DB 변경 경로 · 장애 대응 |
| `design` | 컨셉 · 토큰 · 아이콘 · 톤 |
| `absolute-rules` 2절 | 바꾸면 안 되는 값과 근거 |

한 번에 다 채우지 않는다. **한 스킬만** 채우고 나머지는 다음 「시작해」로 넘긴다.

## 6. 한 걸음이 끝나면

- `상황판.md` 체크리스트에서 끝난 줄을 `- [x]` 로 바꾼다. 다 끝났으면 그 절을 지우고 지금 집중하는 것 한 줄로 바꾼다.
- 「다음에 또 『시작해』라고 하시면 이어서 안내합니다」를 한 줄로 알린다.
- 잰 것과 남은 것을 {{owner}}께 짧게 보고한다. 확인하지 않은 것은 「미확인」이라고 쓴다.

## 하지 말 것

- 할 일을 여러 개 나열하지 않는다. 지금 할 것은 하나다.
- 지금 상태에서 할 수 없는 일을 제안하지 않는다(저장소가 0개면 「저장소별 검사 명령을 채우라」고 하지 않는다).
- 사용자 동의 없이 GitHub 저장소를 만들거나 도구를 설치하거나 전역 설정을 바꾸지 않는다.
- 확인하지 않은 것을 됐다고 말하지 않는다. 상태의 주인은 `harness.json` 과 `doctor` 표다.
